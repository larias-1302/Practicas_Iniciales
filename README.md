# Descripción

Esta práctica consistió en desarrollar un proyecto de **Mantenimiento e Infraestructura de Hardware**, enfocado en el mantenimiento preventivo de una computadora portátil.

En este repositorio se encuentran los entregables solicitados para la práctica, entre ellos:

- Manual técnico del procedimiento de mantenimiento.
- Trifoliar informativo.
- Video tutorial del mantenimiento preventivo.
- Video de configuración y publicación del sitio web mediante Apache.
- Código fuente de la página web desarrollada en HTML y CSS para presentar los entregables.

El objetivo del proyecto es documentar de forma técnica el proceso de mantenimiento preventivo, así como demostrar la implementación de un servidor web para la publicación del contenido.
