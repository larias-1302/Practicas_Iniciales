Proyecto del curso Practicas Iniciales

Proyecto Académico

Este sitio web reúne los entregables correspondientes a la práctica de conectividad de redes desarrollada durante el curso de Prácticas Iniciales de la Universidad de San Carlos de Guatemala. Se documentan las pruebas de comunicación entre equipos físicos y máquinas virtuales mediante el uso de direcciones IP, comandos de diagnóstico como ping y traceroute, así como la configuración necesaria para verificar la conectividad en diferentes escenarios de red.
